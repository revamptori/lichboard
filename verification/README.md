# Verification evidence

`latest.json` is generated by the Android CI job and describes **observed results**, not intended behavior. It identifies the tested source SHA, workflow run, outcome of the build/JVM tests/Lint, outcome of Android 11 (API 30) and Android 15 (API 35) device tests, and the SHA-256 of a release APK only when every stage passes.

- `ci-build.log`: build/test/lint diagnostic tail.
- `ci-emulator-30.log`, `ci-emulator-35.log`: instrumented run output.
- `unit-tests/*.xml`: individual JVM results.
- `api-30/`, `api-35/`: device JUnit reports, logcat crash output, release launch results and actual screenshots.
- `apk-signature.txt`, `apk-badging.txt`: Android SDK validation of the release artifact.

On failure the job still saves diagnostics. `verifiedReleasePublished: false` must not be described as successful device verification. The complete Actions artifact is available through the run URL for its retention period.

Physical-device haptics/audio, OEM background management, actual reboot restore, secure-screen policies, and compatibility with every third-party app are **not** proven by these emulator tests.
